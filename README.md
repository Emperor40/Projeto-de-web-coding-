# Projeto-de-web-coding-

Este projeto web foi desenvolvido por uma equipe dedicada composta por cinco integrantes. O objetivo principal deste trabalho é criar uma página web totalmente voltada para os fãs do jogo Minecraft, oferecendo conteúdos informativos, curiosidades e ferramentas relacionadas ao universo do jogo. Cada membro do grupo colaborou para organizar e programar as funcionalidades do site, tornando-o um espaço acessível e interativo para toda a comunidade de admiradores de Minecraft.
